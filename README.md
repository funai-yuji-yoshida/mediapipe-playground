# MediaPipe お試しラボ

Google MediaPipe でできることを、ブラウザだけで体験・調査できる1枚のWebページです。

## できること（11機能）
| 区分 | 機能 | 入力 |
|---|---|---|
| 顔 | 顔検出／顔の細かい点と表情（52種類） | カメラ・画像・動画 |
| 手 | 手のランドマーク／ジェスチャー認識（7種類） | カメラ・画像・動画 |
| 体 | 姿勢推定（33点） | カメラ・画像・動画 |
| 物 | 物体検出（80種類）／画像分類（1000種類） | カメラ・画像・動画 |
| 切り抜き | 人物の背景切り抜き／クリックした物の切り抜き | カメラ・画像・動画／画像 |
| 音 | 音の分類（521種類） | マイク |
| 文章 | 言語判定 | 文章入力 |

## 使い方
- 右上の **デモ表示**：お客様向け。大きな映像と「業務でこう使える」の一言
- 右上の **調査表示**：FPS・推論時間・読み込み時間、しきい値などの設定、モデル・GPU/CPUの切り替え、結果の生データ（JSON）
- 映像・音声・文章はブラウザ内で処理され、外部には送信されません（初回のみAIモデルをダウンロード）

## 動かし方
- 公開版：GitHub Pages のURLを Chrome / Edge で開く（カメラ・マイクは https で動作）
- 手元で確認：このフォルダで `python -m http.server 8765` を実行し、http://localhost:8765 を開く

## 回線が不安な会場で使う場合
`index.html` 冒頭の `MODEL_BASE` を `./models/` に変え、同じパス構成でモデルファイルを `models/` に置いてください（モデルのURLは各機能の `models` に記載）。
